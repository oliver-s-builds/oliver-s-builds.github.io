# Case Study: Automating User Onboarding


## Problem Statement
A mid-size nonprofit with 500+ employees utilized a manual onboarding process for new hires onto the SSO platform. 
Creating accounts and provisioning access took time and took away from the limited IT staff capacity.

## My Role
I led the project end-to-end. I mapped the workflow, identified automation opportunities, designed workflow, collaborated with HR
and IT on technical requirements and rolled out the process with the HR and IT teams.

## Stack
- Microsoft List: Track employee hires, changes, and offboarding
- Microsoft List Form: HR entry of data
- PowerAutomate and Workato Flows: Automate Employee data changes to Workato
- Workato: SSO platform for organizational access
- Slack: Automated alerts to a staff updates channel for IT and HR

## Approach
1. **Mapped current state** — interviewed IT and HR, documented current manual steps
2. **Identified automation opportunities** — employee detail requirements, department and role access provisioning
4. **Designed workflow** — created decision tree for different user types (staff, contractors, volunteers)
5. **Implemented** — trained HR and IT team, documented handoff

## Key Artifacts
- ADD: Workflow diagram of pre and post automation
- ADD: PowerAutomate to Workato automation template
- ADD: Staff process map and training material

## Results
- **75%+ reduction** in admin time per hire (~30 minutes → 0-10 minutes)
- **Reduced error rate** in access provisioning (previously ~10% manual errors -> 5% manual errors)
- **Repeatable process** — new hires onboarded consistently across departments

## Learnings
Automation isn't about replacing people — it's about removing tedium so they can focus on 
human parts of onboarding (mentoring, culture fit, training). The real win was freeing 
the IT staff to support the organization with challenges instead of cranking through manual entry.
